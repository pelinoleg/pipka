<h1 align="center">Pipka</h1>

<p align="center">Tiny menu bar color picker for macOS. No windows, no clutter.</p>

## Install / update

```bash
curl -fsSL https://raw.githubusercontent.com/pelinoleg/pipka/main/install.sh | bash
```

Or grab `Pipka.zip` from [Releases](https://github.com/pelinoleg/pipka/releases), unzip into `/Applications`
and, since the app isn't notarized, run `xattr -dr com.apple.quarantine /Applications/Pipka.app` once.

Requires macOS 13+, Apple Silicon or Intel.

## How it works

- **Click the drop** in the menu bar (it takes the last picked color) — the system loupe appears, click any pixel, the color is copied.
- **Click the arrow** next to it (or right-click) — the last color in every format. Click a row to copy it;
  that format becomes the default for next picks.
- **⇧⌘C** — pick from anywhere.
- Formats: `#HEX`, `rgb(r, g, b)`, `rgba(r, g, b, 1)`, `hsl(h, s%, l%)`, `oklch()`, `oklab()` (sRGB).
- Launch at login toggle in the popover.

## Build

```bash
./build.sh          # → dist/Pipka.app, dist/Pipka.zip
```

Release: push a tag `vX.Y.Z` — GitHub Actions builds a universal app and attaches it to the release.
The icon is generated by `swift scripts/make-icon.swift`.
